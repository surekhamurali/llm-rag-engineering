# AI Interview Assistant

A local AI-powered technical interview practice application built using Python and Ollama.

## Features

- Multiple technical interview roles.
- Beginner, intermediate, and advanced difficulty levels.
- Automatic technical question generation.
- AI-based candidate answer evaluation.
- Scoring from 1 to 5.
- Strengths and improvement suggestions.
- Suggested interview answers.
- Final interview performance report.
- Structured JSON responses.
- Local LLM execution using Ollama.

## Technologies

- Python
- Ollama
- Llama 3.2 1B
- JSON
- python-dotenv

## Project Architecture

The application separates prompt engineering, LLM communication, and interview management.

- `prompts.py`: Interview and evaluation prompts.
- `llm.py`: Communication with the local Ollama model.
- `main.py`: Interview workflow and user interaction.

## Installation

Install the dependencies:

```bash
pip install -r requirements.txt
```

Install Ollama and ensure your model is available:

```bash
ollama pull llama3.2:1b
```

Configure your `.env` file:

```env
OLLAMA_MODEL=llama3.2:1b
```

## Run

From the repository root:

```bash
python projects/ai-interview-assistant/main.py
```

## Limitations

Evaluation is generated by a local language model and may be inconsistent or factually incorrect. Scores should be treated as practice feedback, not objective assessment.

I would evaluate responses against expected concepts and test the evaluator using a manually reviewed dataset of candidate answers. Q2. How would you scale this application for multiple users?

A good answer:

I would expose the interview functionality through FastAPI, implement session management, and store interview history in a database. I would also consider asynchronous request handling, authentication, rate limiting, logging, and a scalable model-serving architecture.
